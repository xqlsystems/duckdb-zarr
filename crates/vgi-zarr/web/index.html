Zarr SQL in the Browser

DuckDB (Haybarn-wasm) queries weather Zarr stores through a Rust read_zarr worker running in this page over VGI. The worker reads straight from the bucket, and WHERE clauses on dimensions are pushed into it, so it fetches only the chunks (or shard subchunks) that can match.
