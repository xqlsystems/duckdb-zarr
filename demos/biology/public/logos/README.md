# Index logos

These are unmodified upstream SVGs, served locally rather than hotlinked.
Names and marks belong to their respective projects; their use identifies the
file formats/frameworks in this example and does not imply endorsement.

- `anndata.svg` and `spatialdata.svg`: official scverse package icons from
  https://github.com/scverse/scverse.github.io/tree/e3cc2d94383f14a7d36e1f337f3746edd30fac5f/static/img/icons
  Usage guidelines: https://scverse.org/design/
- `ome.svg`: the official Open Microscopy Environment logomark from
  https://www.openmicroscopy.org/img/logos/ome-logomark.svg
  This is the OME mark used by the OME-Zarr specification, not an invented
  standalone OME-Zarr logo. See the specification's header:
  https://github.com/ome/ngff/blob/main/boilerplate/header.include

Preserve original proportions and colors. The images have empty alt text in the
index because their adjacent format names already supply accessible labels.
