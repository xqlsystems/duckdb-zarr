# Examples

Explore Zarr data with DuckDB and SQL. Choose a written SQL walkthrough or an
interactive browser example.

## Climate and geoscience

[Climate and geoscience](climate.md) — existing SQL examples for an
air-temperature map, monthly means, and public precipitation data.

## Biology

[For biologists](../../demos/biology/README.md) — explore single-cell RNA-seq
with an AnnData UMAP and a multichannel 3D fluorescence volume with OME-Zarr.
Edit the SQL, filter the data, and visualize the results. The original public
datasets load only when you open the example.
