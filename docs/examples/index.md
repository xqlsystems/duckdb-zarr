# Examples

Explore Zarr data with DuckDB and SQL. Choose an example to run queries in your
browser and see the results in an interactive visualization.

## Biology

[For biologists](../../demos/biology/README.md) — explore single-cell RNA-seq
with an AnnData UMAP and a multichannel 3D fluorescence volume with OME-Zarr.
Edit the SQL, filter the data, and visualize the results. The original public
datasets load only when you open the example.
